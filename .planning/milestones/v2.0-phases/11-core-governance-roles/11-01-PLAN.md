def fsi_topic_name(topic_def):
    """Assemble topic name from dict with keys: domain, application, version, entity.
    Returns: str in {domain}.{application}.{version}.{entity} format.
    Raises: AnsibleFilterError on missing keys, empty values, or regex mismatches."""

def fsi_sla_lookup(tier, prop):
    """Look up property for SLA tier. tier: critical|standard|best-effort|compliance.
    prop: compatibility|partitions|retention_ms. Returns: str or int."""

    """Validate topic name string. Returns True or raises AnsibleFilterError."""

Admin REST v3 API endpoints:
- GET  /kafka/v3/clusters/{cluster_id}/topics/{topic_name} -> 200 (exists) or 404 (absent)
- POST /kafka/v3/clusters/{cluster_id}/topics -> {topic_name, partitions_count, replication_factor, configs: [{name, value}]}
- POST /kafka/v3/clusters/{cluster_id}/topics/{topic_name}/configs:alter -> {data: [{name, value, operation: "SET"}]}
- DELETE /kafka/v3/clusters/{cluster_id}/topics/{topic_name} -> 200/204
- GET /kafka/v3/clusters/{cluster_id}/topics/{topic_name}/configs -> 200 with configs array

    5. Set `_topic_name` from `topic_item.metadata.name`.
    6. Set `_topic_state` from `topic_item.spec.state | default('present')`.

    **tasks/create.yml** -- GET-before-POST idempotent creation for a single topic. Must:
    1. Build auth headers: if `cp_admin_rest_token` is set, use `Authorization: "Bearer {{ cp_admin_rest_token }}"`. Otherwise use `url_username`/`url_password` with `force_basic_auth: true`.
    2.
