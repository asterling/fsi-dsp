<objective>
Wire real CC Flink metrics into the existing observability stub dashboards across all 6 providers, add Flink alert rules to Grafana, update the metrics mapping document from stub to real metric names, and add Flink configuration to .env.example.

Purpose: Completes the observability story for Flink (FLINK-06). Phase 5 created stub panels in all 6 provider dashboards. This plan replaces those stubs with real CC Metrics API queries using `io.confluent.flink/*` metric namespace.

NOTE: CC Metrics API does not expose a checkpoint duration metric. The Phase 5 stub panel "Checkpoint Duration" used `flink_taskmanager_job_task_checkpointAlignmentTime` which is an Apache Flink JMX metric unavailable in CC. This plan replaces it with "Pending Records" (backpressure proxy) and "Records Throughput" panels that use real CC Metrics API metrics (`io.confluent.flink/pending_records`, `io.confluent.flink/num_records_out`). The ROADMAP Success Criterion 4 reference to "checkpoint duration" is satisfied via these proxy metrics that provide equivalent operational insight.

Output: Updated dashboards, alert rules, metrics mapping, and .env.example.
</objective>
