Use New Relic dashboard JSON format with 5 pages (one per panel area):

- **Cluster Health page**: Billboard widget (broker count), Billboard widget (under-replicated partitions, critical threshold >=1), Line chart (request rate), Billboard (active controller). NRQL queries: `SELECT uniqueCount(entityName) FROM KafkaBrokerSample WHERE clusterName = '{{CLUSTER_ID}}'`, `SELECT latest(broker.underReplicatedPartitions) FROM KafkaBrokerSample`, etc.

- **Consumer Lag page**: Line chart widget with NRQL `SELECT max(consumer.totalLag) FROM KafkaConsumerSample WHERE topic LIKE '{{DOMAIN_PREFIX}}%' FACET consumerGroup TIMESERIES` (auto-discovery via LIKE wildcard per D-09). Table widget with per-partition lag: `SELECT latest(consumer.lag) FROM KafkaConsumerSample FACET consumerGroup, topic, partition`. Threshold lines at SLA-tier values.

- **Connect Status page**: Table widget with NRQL `SELECT latest(connector.status) FROM KafkaConnectSample FACET connectorName`. Billboard for FAILED count: `SELECT filter(uniqueCount(connectorName), WHERE connector.status = 'FAILED') FROM KafkaConnectSample`. Colors: RUNNING=#22C55E, FAILED=#EF4444.

- **DR Readiness page**: Line chart with mirror lag per topic. NRQL `SELECT latest(replication.mirrorLagMs) / 1000 AS 'Mirror Lag (seconds)' FROM KafkaClusterLinkSample FACET mirrorTopicName TIMESERIES`. Threshold lines per SLA tier. Mirror topics colored #3B82F6.

- **Flink Jobs page**: Markdown widget with text "Flink metrics will be available after Phase 6 deployment. This panel shows placeholder structure." Background gray.

Widget layout: Each widget includes `row`, `column`, `width`, `height` per New Relic dashboard grid.

**alerts.json** -- Array of NRQL alert condition definitions:
- Each condition has `name`, `nrql.query`, `terms` (with `threshold`, `duration`, `operator`, `priority`)
- Mirror lag alerts per tier:
  - `MirrorLagCritical`: NRQL `SELECT max(replication.mirrorLagMs)/1000 FROM KafkaClusterLinkSample WHERE sla_tier = 'critical'`, warning at 30, critical at 60
  - `MirrorLagStandard`: warning at 300, critical at 900
  - `MirrorLagBestEffort`: warning at 3600, critical at 14400
  - `MirrorLagCompliance`: warning at 10, critical at 30
- Consumer lag alerts per tier:
  - `ConsumerLagCritical`: NRQL with threshold warning=1000, critical=5000
  - `ConsumerLagStandard`: warning=10000, critical=50000
  - `ConsumerLagBestEffort`: warning=100000, critical=500000
  - `ConsumerLagCompliance`: warning=500, critical=2000
- `ConnectTaskFailed`: NRQL `SELECT filter(count(*), WHERE connector.status = 'FAILED') FROM KafkaConnectSample`, critical at >=1
- `ConnectTaskRestartLoop`: NRQL restart count >= 3 in 15m, warning
- `UnderReplicatedPartitions`: NRQL under-replicated > 0 for 5m, critical
