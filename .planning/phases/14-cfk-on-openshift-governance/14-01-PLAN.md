- Load role defaults

**5. Create ansible/roles/cfk_operator/tasks/deploy.yml** -- Helm-based operator install:
- Task "Add Confluent Helm repository" using `kubernetes.core.helm_repository` with `name: "{{ cfk_helm_repo_name }}"`, `repo_url: "{{ cfk_helm_repo_url }}"`, `state: present`
- Task "Deploy CFK operator via Helm" using `kubernetes.core.helm` with `name: "{{ cfk_helm_release_name }}"`, `chart_ref: "{{ cfk_helm_chart_ref }}"`, `chart_version: "{{ cfk_helm_chart_version }}"`, `release_namespace: "{{ cfk_namespace }}"`, `create_namespace: true`, `wait: true`, `wait_timeout: "{{ cfk_helm_wait_timeout }}"`. Register `_cfk_helm_result`.
- Task "Report Helm deployment result" using `ansible.builtin.debug` with `msg` showing release status. Use `when: _cfk_helm_result is defined`.

**6. Create ansible/roles/cfk_operator/tasks/apply_crs.yml** -- Apply CRs with readiness polling:
- For each CR (kafka, schema_registry, connect), use a block that:
  a. Task "Apply {Kind} custom resource" using `kubernetes.core.k8s` with `state: present`, `src: "{{ cfk_{kind}_cr_path }}"`, `namespace: "{{ cfk_namespace }}"`. Use `when: cfk_{kind}_cr_path | length > 0`.
  b. Task "Wait for {Kind} to reach RUNNING state" using `kubernetes.core.k8s_info` with `kind:` set to the CFK CRD kind (Kafka, SchemaRegistry, Connect), `api_version: platform.confluent.io/v1beta1`, `namespace: "{{ cfk_namespace }}"`. Register result. Use `until` loop checking `resources | length > 0` AND `resources[0].status.phase | default('') == cfk_expected_status_phase`. Set `retries: "{{ cfk_readiness_retries }}"`, `delay: "{{ cfk_readiness_delay }}"`. Use `when: cfk_{kind}_cr_path | length > 0`.
- IMPORTANT: Use the k8s_info + until/retries/delay pattern (NOT wait_condition) per Research Pitfall 1 and Pitfall 6.

**7. Create ansible/roles/cfk_operator/tasks/check.yml** -- Check-mode audit:
- Task "Query CFK Helm release status" using `kubernetes.core.helm_info` with `name: "{{ cfk_helm_release_name }}"`, `release_namespace: "{{ cfk_namespace }}"`. Register `_cfk_helm_info`.
- Task "Report CFK operator status" using `ansible.builtin.debug`.
- For each CR kind (Kafka, SchemaRegistry, Connect):
  Task "Query {Kind} CR status" using `kubernetes.core.k8s_info` with `kind`, `api_version: platform.confluent.io/v1beta1`, `namespace: "{{ cfk_namespace }}"`. Register result and report via debug.

```yaml
  tags:

  gather_facts: false

```
