```python
"""FSI C4E Reference Producer -- Python.

Mirrors Java FsiProducer: idempotent, Avro, metrics, graceful shutdown, DLQ routing.
This is a reference implementation. Copy and adapt for your application.
"""

import logging
import threading
import time

from confluent_kafka import Producer, KafkaError, KafkaException
from confluent_kafka.schema_registry import SchemaRegistryClient
from confluent_kafka.schema_registry.avro import AvroSerializer
from confluent_kafka.serialization import StringSerializer, SerializationContext, MessageField
from prometheus_client import Counter, Gauge, start_http_server

from fsi_dlq_handler import FsiDlqHandler
```

**Constructor** `__init__(self, config: dict)`:
- Required config key: `topic.name` (raise ValueError if missing)
- Optional keys: `bootstrap.servers` (default: "localhost:9092"), `schema.registry.url` (default: "http://localhost:8081"), `schema.registry.basic.auth.user.info`, `sasl.username`, `sasl.password`, `value.schema` (Avro schema JSON string), `client.id`, `dlq.enabled` (default: "true"), `metrics.port` (default: "9090")
- Create SchemaRegistryClient with url and optional basic.auth.user.info
- Create AvroSerializer with `to_dict=lambda obj, ctx: obj` (pass dicts directly)
- Create StringSerializer('utf_8') for keys
- Create Producer with these C4E mandatory settings:
  - `enable.idempotence`: True
  - `acks`: "all"
  - `max.in.flight.requests.per.connection`: 5
  - `retries`: 2147483647
  - `delivery.timeout.ms`: 120000
  - `request.timeout.ms`: 30000
  - `compression.type`: "zstd"
  - `batch.size`: 32768
  - `linger.ms`: 20
  - `client.id`: config.get('client.id', f'fsi-{topic_name.split(".")[0]}-producer-python')
- Add SASL config only if `sasl.username` is provided: `security.protocol`="SASL_SSL", `sasl.mechanism`="PLAIN"
- Create prometheus_client metrics:
  - `Counter('fsi_producer_total_sent', 'Total messages sent successfully', ['topic'])`
  - `Counter('fsi_producer_total_errors', 'Total send errors', ['topic'])`
  - `Gauge('fsi_producer_last_latency_ms', 'Last send latency in milliseconds', ['topic'])`
  - `Counter('fsi_producer_dlq_sent', 'Total messages routed to DLQ', ['topic'])`
- Start metrics HTTP server on config `metrics.port` (default 9090) in daemon thread
- If `dlq.enabled` != "false", create FsiDlqHandler instance

**Methods:**
- `send(self, key: str, value: dict)` — Async send with callback. Serialize key with StringSerializer, value with AvroSerializer. On delivery callback: if err, increment total_errors, route to DLQ handler; if success, increment total_sent, record latency.
- `send_sync(self, key: str, value: dict) -> dict` — Synchronous send. Produce, then `flush()`. Return dict with `topic`, `partition`, `offset`. Raise on error.
- `flush(self)` — Call `self._producer.flush()`
- `close(self)` — Flush with 30s timeout, log final metrics (total_sent, total_errors, dlq_sent).
- Support context manager: `__enter__` returns self, `__exit__` calls close.

```python
Routes failed messages to {source-topic}.dlq with error categorization,
```

**Error categorization (per D-11):**
```python
NON_RETRYABLE_ERRORS = {
    KafkaError._VALUE_SERIALIZATION,
    KafkaError._KEY_SERIALIZATION,
    KafkaError._VALUE_DESERIALIZATION,
    KafkaError._KEY_DESERIALIZATION,
    KafkaError.TOPIC_AUTHORIZATION_FAILED,
    KafkaError.GROUP_AUTHORIZATION_FAILED,
    KafkaError.CLUSTER_AUTHORIZATION_FAILED,
}
```

**Constructor** `__init__(self, producer_config: dict, source_topic: str)`:
- Create a separate `Producer` instance for DLQ writes (uses same bootstrap.servers and SASL config)
- Store `dlq_topic = f"{source_topic}.dlq"` (per D-12)
- Create prometheus Counter `fsi_dlq_handler_total_sent` with labels `['source_topic', 'error_type']`

**Methods:**
- `handle_error(self, key: bytes, value_bytes: bytes, error, retry_count: int = 0)`:
  - Classify error: if error code in NON_RETRYABLE_ERRORS, send directly to DLQ
  - If retryable and retry_count < 3: return `("retry", backoff_seconds)` where backoff = 1 * (2 ** retry_count) + random.uniform(0, 0.1 * (2 ** retry_count))
  - If retryable and retry_count >= 3: send to DLQ
  - DLQ headers (per research recommendation):
    - `dlq.original.topic`: source topic name (utf-8 bytes)
    - `dlq.error.type`: one of SERIALIZATION, SCHEMA_INCOMPATIBLE, BROKER_TIMEOUT, AUTH_DENIED, UNKNOWN (utf-8 bytes)
    - `dlq.error.message`: str(error)[:1024] (utf-8 bytes)
    - `dlq.timestamp`: ISO 8601 UTC timestamp (utf-8 bytes)
    - `dlq.retry.count`: str(retry_count) (utf-8 bytes)
    - `dlq.producer.client.id`: client.id from config (utf-8 bytes)
  - Produce to dlq_topic with same key, original value_bytes, and headers
  - Increment prometheus counter with source_topic and error_type labels
- `_classify_error(self, error) -> str`: Map KafkaError codes to human-readable categories
- `close(self)`: Flush DLQ producer with 10s timeout
