<objective>
Create the cp_dr_mm2 Ansible role with the complete failover sequence (pause connectors, stop MM2, flip Consul, validate, resume), dry-run check mode with audit output, state validation against SLA-tier thresholds, and the operator-facing failover playbook.

Purpose: Replace manual shell-based MM2 DR failover with a structured Ansible playbook that supports --check mode for audit-ready dry-run output and validates state between steps.
Output: cp_dr_mm2 role (defaults, meta, 7 task files, molecule scenario), dr-failover-mm2.yml playbook, sla_tiers.yml mirror lag thresholds, mock fixtures, and unit tests.
