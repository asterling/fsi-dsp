**Pure functions (testable without external deps):**

`assess_lag()` -- Takes lag_sec and tier, returns "OK", "WARN", or "ALERT" based on thresholds from arrays above.

`get_tier_threshold()` -- Takes tier, returns alert threshold in seconds.

`get_tier_warn_threshold()` -- Takes tier, returns warn threshold in seconds.

`format_duration()` -- Takes seconds, returns human-readable "Xs", "Xm Ys", "Xh Ym" string.

**State file functions** (per D-07, atomic writes via mktemp+mv):

`init_state()` -- Takes operation name ("failover"/"failback"). Creates JSON: `{operation, started (ISO timestamp), backend, steps_completed: [], connectors_snapshot: [], topics_promoted: [], current_step: 0, status: "in-progress"}`. Uses `jq -n` to create, `mktemp "${STATE_FILE}.XXXXXX"` + `mv` for atomic write.

`record_step()` -- Takes step_num and step_name. Appends to steps_completed array with timestamp, updates current_step.

`record_connectors()` -- Takes JSON array of connector states, stores in connectors_snapshot.

`record_topics()` -- Takes space-separated topic names, stores in topics_promoted array.

`cleanup_state()` -- Removes state file on successful completion. Sets status to "completed" first.

`read_state()` -- Returns state file contents or empty object if no file.

**Connect state tracking** (per D-08, DR-12):

`snapshot_connectors()` -- Calls `curl -s "${FSI_CONNECT_URL}/connectors?expand=status"` and transforms with `jq` to extract: `[{name, state, tasks: [{id, state}]}]`. Returns the JSON array. Stores in state file via `record_connectors()`.

`get_running_connectors()` -- Reads connectors_snapshot from state file, filters where state == "RUNNING", returns connector names.

`pause_connector()` -- Takes connector name, issues `curl -s -X PUT "${FSI_CONNECT_URL}/connectors/${name}/pause"`. Polls status up to 30 iterations (2s sleep) until state is PAUSED or timeout.

`resume_connector()` -- Takes connector name, issues `curl -s -X PUT "${FSI_CONNECT_URL}/connectors/${name}/resume"`. Polls until RUNNING or timeout.

**Pre-flight checks** (per D-11):

`preflight_check()` -- Runs 5 checks, tracks pass/warn/fail counts:
1. Production cluster reachable: `confluent kafka cluster describe "${FSI_DR_CLUSTER_ID}" --environment "${FSI_DR_ENV_ID}" -o json 2>/dev/null`
2. DR cluster reachable: same for DR cluster IDs
3. Active mirrors on DR: `confluent kafka mirror list --link "${FSI_CLUSTER_LINK_NAME}" --cluster "${FSI_DR_DR_CLUSTER_ID}" --environment "${FSI_DR_DR_ENV_ID}" -o json | jq 'length'`
4. Connect API reachable: `curl -sf "${FSI_CONNECT_URL}/" >/dev/null 2>&1`
5. Consul reachable: `curl -sf "${CONSUL_HTTP_ADDR}/v1/status/leader" >/dev/null 2>&1`

Production cluster unreachable = WARN (expected during DR event). DR cluster unreachable = FAIL. No active mirrors = FAIL. Connect/Consul unreachable = FAIL. Return non-zero if any FAIL.

Print summary: "Pre-flight: X passed, Y warnings, Z failed".

**Mirror lag functions:**

`get_mirror_lag_json()` -- Calls `confluent kafka mirror list --link "${FSI_CLUSTER_LINK_NAME}" --cluster "${FSI_DR_DR_CLUSTER_ID}" --environment "${FSI_DR_DR_ENV_ID}" -o json` and returns raw JSON.

`get_topic_sla_tier()` -- Takes topic name. Tries `confluent kafka topic describe "${topic}" --cluster "${FSI_DR_CLUSTER_ID}" --environment "${FSI_DR_ENV_ID}" -o json | jq -r '.configs[] | select(.name == "confluent.placement.constraints") // empty'` first. If sla-tier not found in topic config, falls back to schema subject metadata lookup via `confluent schema-registry subject describe "${topic}-value" -o json | jq -r '.metadata.properties["sla-tier"] // "standard"'`. Default to "standard" if lookup fails (per Claude's discretion).

**CLI argument parsing:**
```bash
main() {
  local cmd="${1:-help}"
  shift || true
  # Parse global flags
  DRY_RUN=false; FORCE=false
  while [[ $# -gt 0 ]]; do
    case "$1" in
      --dry-run) DRY_RUN=true; shift ;;
      --force)   FORCE=true; shift ;;
      *)         echo "Unknown flag: $1"; usage; exit 1 ;;
    esac
  done

  case "${cmd}" in
    failover) load_env; cmd_failover ;;
    failback) load_env; cmd_failback ;;
    status)   load_env; cmd_status ;;
    help|-h|--help) usage ;;
    *) echo "Unknown command: ${cmd}"; usage; exit 1 ;;
  esac
}
```

```bash
#!/usr/bin/env bash
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
REPO_ROOT="$(cd "${SCRIPT_DIR}/../.." && pwd)"
PASS=0; FAIL=0; TOTAL=0

# Create temp dir for state files
TEST_TMPDIR=$(mktemp -d)
trap 'rm -rf "${TEST_TMPDIR}"' EXIT

# Override state file location for tests
export FSI_DR_STATE_FILE="${TEST_TMPDIR}/fsi-dr-state.json"

# Source fsi-dr.sh functions (SOURCED guard prevents main execution)
source "${REPO_ROOT}/scripts/fsi-dr.sh"

assert_eq() {
  local test_name="$1" expected="$2" actual="$3"
  ((TOTAL++))
  if [ "${expected}" = "${actual}" ]; then
    echo "  PASS: ${test_name}"
    ((PASS++))
  else
    echo "  FAIL: ${test_name} (expected='${expected}', actual='${actual}')"
    ((FAIL++))
  fi
}

assert_exit_code() {
  local test_name="$1" expected_code="$2"
  shift 2
  local actual_code=0
  "$@" >/dev/null 2>&1 || actual_code=$?
  ((TOTAL++))
  if [ "${expected_code}" = "${actual_code}" ]; then
    echo "  PASS: ${test_name}"
    ((PASS++))
  else
    echo "  FAIL: ${test_name} (expected exit ${expected_code}, got ${actual_code})"
    ((FAIL++))
  fi
}
```
