## Deferred Verification

### kustomize build (overlays/dev + overlays/prod)

**Status: Deferred — base/upstream/ not populated on this machine.**

`kustomize build` requires `base/upstream/` to be populated by `fetch-upstream.sh`. The upstream SHA in `fetch-upstream.sh` is a placeholder (`a1b2c3d4e5...`) that will not resolve until updated to a real SHA. Once the real SHA is set:

```bash
cd accelerators/confluent-on-linuxone
flox activate   # or: bash base/fetch-upstream.sh
kustomize build overlays/dev > /dev/null && echo "dev: OK"
kustomize build overlays/prod > /dev/null && echo "prod: OK"
```

The CI workflow runs this automatically via `fetch-and-build` job.

### kubeconform CRD lint

**Status: Deferred — kubeconform not available on this machine.**

CFK CRDs (`platform.confluent.io/v1beta1`) are not in the default kubeconform schema registry. The CI workflow runs kubeconform with `--ignore-missing-schemas` so it lints standard Kubernetes resource types (cert-manager, Route, Job, ConfigMap) while tolerating unknown CFK CRDs.

### Cluster-dependent validators

`validate-rbac.sh`, `validate-mtls.sh`, `validate-schema-governance.sh`, `validate-audit.sh` are authored and syntactically valid (all pass `bash -n`). They require an OCP-on-LinuxONE cluster. Run per `RUNBOOK.md` steps 5-8.
